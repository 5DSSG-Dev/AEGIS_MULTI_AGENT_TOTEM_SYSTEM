# AEGIS Totem v0.1.1-alpha.1

Status: Public alpha release candidate authorized by Tracey on 2026-10-17. Publication is complete only when the GitHub Release and assets are verified.

## Summary

AEGIS Totem is a free, local-first developer tool for append-only repository continuity and multi-agent coordination. It gives a repository a Root Totem, Folder Totems, and one lane per human, agent, model, or instance so parallel work can coordinate without a copy/paste bridge.

## Included In This Alpha

- TypeScript CLI with `start`, structured Start JSON, generated Root Totem tutorial for new AI agents, `init`, lane creation, lane messaging, Folder Totem creation, Folder Totem appends, `status`, filtered list, read commands, analytics, validation, readiness doctor with JSON output, MCP config generation, and optional local validation hook installation.
- Append-only write helper with lock-directory serialization for concurrent agent writes.
- MCP stdio server exposing start, read, append, status, list, analytics, validation, and doctor tools for AI coding agents.
- MCP client examples for Codex, Cursor, Claude Desktop, Cline, Windsurf, and other stdio clients.
- VS Code extension adapter with a dedicated Activity Bar icon, visible sidebar command rows, `Initialize System`, and `AEGIS Totem: Start`, backed by a bundled alpha CLI runtime for existing-repo seeding, automatic Doctor readiness after Start, browsing Totems and lanes, viewing read-only List, Analytics, structured Doctor, and Live Test Checklist panels, sending lane messages, and appending Folder Totem updates.
- Cursor/Open VSX readiness docs and QA over the same VS Code-compatible VSIX package path.
- Local install QA, MCP QA, VS Code package QA, Cursor/Open VSX readiness QA, docs QA, release preflight, CI, release checklist, security policy, and quickstart documentation.

## Installation During Alpha

Download `aegis-totem-0.1.1.tgz` from the GitHub Release assets, then run:

```bash
npm install -g ./aegis-totem-0.1.1.tgz
aegis-totem --help
```

Requires Node.js 20 or newer and npm. Runtime dependencies are fetched from npm. Registry publication (`npm publish`) is not part of this GitHub alpha distribution.

Source build:

```bash
npm ci
npm run alpha:check
npm link
```

## VS Code Alpha Install

Build and install the local VS Code package:

```bash
npm run vscode:qa
code --install-extension dist/aegis-totem-vscode-0.1.1.vsix
```

On Windows, install the `.vsix` from inside VS Code. Double-clicking the file can route it to the Visual Studio VSIX Installer and produce a false install failure.

This alpha includes the initial AEGIS Totem VS Code icon at `vscode-extension/media/aegis-totem-icon.png`.

## Cursor Alpha Install

Cursor uses the same VS Code-compatible VSIX package during local alpha testing:

```bash
npm run vscode:qa
npm run cursor:qa
```

Install `dist/aegis-totem-vscode-0.1.1.vsix` from Cursor with `Extensions` -> `...` -> `Install from VSIX...`.

Developers building the extension from source should review the current audit. The packaged extension includes Commander and Zod for the CLI; it does not bundle the MCP SDK or an independently runnable MCP server dependency tree.
