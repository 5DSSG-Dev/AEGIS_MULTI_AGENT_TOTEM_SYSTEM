# AEGIS Totem v0.1.2-alpha.1

Free MIT public alpha. This release combines published CLI0.1.2 and extension0.1.3. Their versions are independent.

## CLI0.1.2

Fixes silent startup through NVM linked global install directories. Entry-point detection compares physical filesystem paths. The owner verified actual global --version and --help output. Published through npm publish with alpha tag. Install using npm install -g aegis-totem@alpha. The default latest tag requires a separate owner-authenticated update if it still points to0.1.1.

## VS Code extension0.1.3

Includes Doctor readiness-report handling, Git/Mercurial/Subversion metadata exclusions, corrected repository metadata, and a small256x256 icon. Install the VSIX through Extensions -> ... -> Install from VSIX. Both editor registries were still0.1.2 when this release was prepared. Registry0.1.3 updates and fresh editor UI checks remain pending. This GitHub Release does not itself update Marketplace/Open VSX installations.

Important: older extension watchers can create TOTEM.md inside .git/refs and disrupt Git. Upgrade to the corrected extension. Existing misplaced files need separate backed-up cleanup; the extension does not remove them automatically.

## Assets and validation

The CLI tarball is downloaded from the actual npm registry, preserving its published bytes. The extension VSIX is built from this release source. SHA256SUMS.txt covers both assets. Existing0.1.1 GitHub release history is preserved; use this newer release for corrected binaries.

Local-source verification:53 tests, typecheck, build, fresh-package installation QA, MCP integration, packaged VSIX CLI/adapter smoke, Cursor metadata/docs QA, docs QA and preflight. The user verified public global CLI version/help. Broader fresh-project execution of the public global installation remains pending because agent execution was blocked by policy. Manual UI/third-party editor behavior remains separate. These tools do not lock source files or guarantee collision-free work.
