# AEGIS Totem v0.1.2-alpha.1

CLI package version 0.1.2 fixes silent --version, --help and other commands when launched through an NVM-style directory link. The entrypoint now compares real filesystem paths. Two regression cases reproduced the old behavior before repair. The CLI version and extension version are independent; the local VS Code package remains 0.1.3.

Publication: npm publish --access public --tag alpha. GitHub Release publication is separate. This file is preparation, not proof of registry availability.

After npm publication: npm install -g aegis-totem@alpha, then aegis-totem --version should print0.1.2 and --help should print commands. Do not treat publish success or successful dependency installation as proof that the command shim works.
